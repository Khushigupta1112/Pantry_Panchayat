# 🍳 Pantry Panchayat

### *Because deciding what to cook with your roommate shouldn't become a debate.*

🔗 **Live:** https://pantry-panchayat.vercel.app/

## 😂 Why I built this

Me and my roommate were constantly fighting over one question:

> **"What should we cook today?"**

One says *"you decide"*, the other says *"anything is fine"* — and 30 minutes later, we're still deciding. 😭

So I built **Pantry Panchayat** to settle the argument.

## ⚖️ What it does

Give the Panchayat your available ingredients / situation, and let AI make the final call.

**No arguing. No overthinking. Just a verdict.**

```text
🥔 Ingredients
      ↓
🤖 AI
      ↓
⚖️ Panchayat Verdict
      ↓
🍛 Dinner
```

## 🛠️ Built With

* React / Next.js
* JavaScript
* AI / LLM
* Git & GitHub
* Vercel

## 💡 What I learned

This project helped me understand how to take a **small real-life problem**, turn it into a usable product, integrate AI into it, and actually deploy it.

The goal wasn't to build another AI chatbot.

It was to build something **my roommate and I would actually use.**
